# 金线 (Golden Thread) - Web 版

把认知转化为可执行系统的Web应用

## 技术栈

- React 18
- TypeScript
- Vite
- React Router 6
- Tailwind CSS

## 功能特性

### 核心功能

✅ **今日执行** - 简洁展示需要执行的协议，突出最小动作
✅ **协议创建** - 6个步骤的结构化表单，强制具体输入
✅ **协议管理** - 查看、删除、查看详细执行历史
✅ **自动降级系统** - 连续失败3次自动降低难度
✅ **自动升级系统** - 连续成功5次可以增加挑战
✅ **周复盘功能** - 每周三问，系统优化而非自我批评
✅ **本地存储** - 数据自动保存到浏览器

### 智库功能

✅ **需求解析** - 分析模糊需求，拆解成可执行问题
✅ **问题提取** - 提取核心问题，区分表面和深层问题
✅ **任务拆解** - 把目标拆解成小任务，设定优先级
✅ **行动方案** - 制定具体执行计划，设定里程碑
✅ **思维框架** - 提供结构化思考框架，多维度分析
✅ **资源规划** - 盘点资源，识别缺口，优化配置
✅ **风险评估** - 识别风险，评估影响，制定应对策略
✅ **执行复盘** - 回顾过程，分析原因，总结经验
✅ **自定义模块** - 可添加、编辑、删除模块，自定义提示词
✅ **模块切换** - 聊天时随时切换不同模块

### 读书功能

✅ **本地书籍导入** - 支持 .txt、.md、.epub、.zip 格式
✅ **在线书源** - 支持导入书源，搜索网络小说
✅ **书源管理** - 添加、编辑、测试、调试书源
✅ **阅读体验** - 字体大小、行间距、主题调节
✅ **朗读功能** - 支持浏览器朗读，可调节语速
✅ **进度同步** - 自动保存阅读进度
✅ **在线阅读** - 支持在线阅读网络小说

### AI 助手

✅ **AI 对话** - 支持 DeepSeek、OpenAI 格式 API
✅ **流式输出** - 实时显示 AI 回复
✅ **语音输入** - 支持语音输入
✅ **图片上传** - 支持发送图片
✅ **联网搜索** - 支持 SerpAPI 联网搜索
✅ **语音朗读** - 支持浏览器朗读 AI 回复

## 核心设计理念

### 1. 最小动作优先
- 永远从最小动作开始
- 行动一旦启动，惯性会接管
- 避免"全或无"的思维

### 2. 自动降级系统
- 连续失败3次 → 自动降低难度
- 缩小最小动作
- 减少频率
- 这让你的系统和你一起成长，而不是对抗

### 3. 自动升级系统
- 连续成功5次 → 可以增加挑战
- 延长时长
- 增加频率

### 4. 系统优化，而非自我批评
- 复盘时不问"我为什么这么懒"
- 而是问"我的系统哪里设计错了"
- 你是系统的设计者，不是执行者

## 如何创建第一个协议

### 示例：读书习惯

1. 点击 **+ 创建协议**
2. **基本信息**：
   - 行动原则：提升认知
   - 目标类型：习惯养成
   - 优先级：4
3. **触发机制**：
   - 触发类型：时间触发
   - 触发条件：22:00
   - 执行时间窗口：22:00-22:30
   - 频率：每天
4. **执行动作**：
   - 标准动作：打开书读5页
   - 最小动作：读1页
   - 最大时长：30分钟
5. **环境设计**：
   - 事前准备：晚饭后把书放桌上
   - 降低阻力：打开灯+清理桌面
   - 增加阻力：手机放客厅
6. **反馈系统**：
   - 奖励机制：完成后看视频10分钟
7. 点击 **保存协议**

## 如何使用智库

1. 点击导航栏的 **🚀 智库**
2. 从左侧选择一个模块（如"需求解析"）
3. 在右侧输入框描述你的需求
4. AI 会根据当前模块的提示词进行回复
5. 聊天时可以随时点击输入框上方的模块按钮切换

### 自定义模块

- 鼠标悬停在模块按钮上，点击 **✏️** 编辑
- 修改模块名称和提示词
- 点击 **保存** 立即生效
- 点击 **+** 添加新模块

## 如何使用读书功能

### 导入本地书籍

1. 点击导航栏的 **📚 读书**
2. 点击 **+ 导入书籍**
3. 选择 .txt、.md、.epub 或 .zip 文件
4. 书籍自动添加到书架

### 使用书源

1. 点击 **书源管理**
2. 粘贴书源 JSON 或导入书源文件
3. 点击 **网络书源** 搜索小说
4. 点击章节在线阅读，或导入全本
